# vulnerable-react-app (github.com/vulnerable-apps/vulnerable-react-app) — a React SPA frontend (reactvulna)
# over a Java Spring REST API (javulna). Added specifically to benchmark SPA -> REST discovery/coverage: the
# vulns live in the /rest/* API, but a scanner only reaches them by mining the SPA's JS.
# No scoreboard API, so — like DVWA/crAPI/vAPI — "found" = the scanner's own
# exported report (bench/results/reactvulna.report.txt); each vuln-CLASS id below is matched (case-insensitive,
# word-boundary substring) against the report lines. Deploy out-of-band (its own docker compose, see run.sh).
#
#   class (below)             endpoint (javulna)                     automated-reachability (our probes / Burp)
#   ----------------------    -----------------------------------    ------------------------------------------
#   SQL injection             GET  /rest/movie?...                   yes  — Burp SQLi + BlindSqliProbe
#   cross-site scripting      movie create/display (reflected)       yes  — Burp reflected XSS / EvasionXssProbe
#   path traversal            GET  /downloadFile?fileName=           yes  — PathTraversalProbe + Burp
#   broken access control     POST /rest/user/password (change any)  yes  — BflaProbe / IdorGetProbe
#   file upload               POST /uploadFile (no validation)       partial — upload probing (type/traversal)
#   XML external entity       POST /rest/moviexml                    partial — XxeProbe (blind; needs OOB)
#   XML injection             POST /rest/user/password (str concat)  partial — Burp XML injection
#   LDAP injection            GET  /rest/ldap?username=&password=    partial — Burp LDAP injection (no own probe)
#   insecure deserialization  serialized cookie (commons-collections) no   — needs a gadget/deserialization probe
#   price manipulation        PUT  /rest/order (client sets price)   no   — business-logic (BodyMutatorProbe-ish)
#
# Denominator = the vuln CLASSES javulna exposes. Score = how many our report names; naming gaps just lower the
# score honestly (extend the scorer's ALIASES map if our probe names a class differently).
